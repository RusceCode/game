# Sterrensprint

Een simpele browsergame die je meteen kunt spelen.

## Doel
- Verzamel gele sterren voor punten.
- Ontwijk rode asteroïden.
- Je hebt 3 levens.

## Besturing
- **Links/rechts bewegen:** `←` `→` of `A` `D`
- **Springen:** `Spatie`
- **Opnieuw starten:** knop "Opnieuw starten"

## Starten
Open `index.html` in je browser.

Of start een lokale server:

```bash
python3 -m http.server 8000
```

Ga daarna naar `http://localhost:8000`.
